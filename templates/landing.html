{% trans "Généralités" %}

Q1 {% trans "Qu'est-ce que KaramuManage ?" %}

{% trans "KaramuManage est une plateforme professionnelle de gestion d'événements qui vous permet d'organiser facilement vos événements (mariages, anniversaires, événements corporatifs, etc.). Elle vous accompagne de l'invitation à la gestion le jour J : import d'invités, gestion des tables, prévisions de dépenses, génération d'invitations PDF, check-in par QR code et bien plus encore." %}

Q2 {% trans "Est-ce que KaramuManage est gratuit ?" %}

{% trans "Oui ! KaramuManage propose un plan gratuit qui vous permet d'organiser un événement avec jusqu'à 50 invités et 2 co-organisateurs. Vous pouvez découvrir toutes les fonctionnalités sans aucun engagement. Pour des événements plus importants, des plans payants sont disponibles avec des capacités étendues." %}

Q3 {% trans "Quels types d'événements puis-je gérer avec KaramuManage ?" %}

{% trans "Vous pouvez gérer tous types d'événements : mariages, anniversaires, anniversaires de mariage, événements corporatifs, remises de diplôme, soirées privées, réunions familiales, et bien d'autres. L'outil s'adapte à vos besoins." %}

Q4 {% trans "Comment créer mon compte ?" %}

{% trans "Rendez-vous sur la page d'inscription, remplissez vos informations (nom, email, mot de passe) et confirmez votre email. En quelques secondes, vous avez accès à votre tableau de bord et pouvez commencer à créer votre premier événement." %}

{% trans "Création et gestion d'événements" %}

Q5 {% trans "Comment créer un événement ?" %}

{% trans "Dans votre tableau de bord, cliquez sur 'Nouvel événement'. Remplissez les informations essentielles : nom, type d'événement, date, heure, lieu. Vous pouvez également ajouter une description, un code vestimentaire, une photo et choisir les options de boissons. Une fois créé, vous pouvez commencer à inviter vos convives." %}

Q6 {% trans "Puis-je modifier un événement après sa création ?" %}

{% trans "Oui, vous pouvez modifier votre événement à tout moment. Cliquez sur 'Modifier' dans la page de détail de l'événement. Toutes les informations sont modifiables : nom, date, lieu, description, options, etc. Les invités déjà importés conservent leurs données." %}

Q7 {% trans "Comment supprimer un événement ?" %}

{% trans "Dans la page de détail de votre événement, cliquez sur le bouton 'Supprimer' (icône poubelle). Une confirmation vous sera demandée. La suppression est définitive et irréversible. Toutes les données liées à l'événement (invités, tables, réponses) seront également supprimées." %}

{% trans "Gestion des invités" %}

Q8 {% trans "Comment importer mes invités ?" %}

{% trans "Rendez-vous dans la section 'Invités' de votre événement, puis cliquez sur 'Importer'. Téléchargez un fichier Excel (.xlsx) avec les colonnes suivantes : Prénom, Nom, Postnom (optionnel), Email (optionnel), Téléphone (optionnel), Table (optionnel). Les invités sont automatiquement ajoutés à votre liste. Les tables mentionnées sont créées automatiquement si elles n'existent pas." %}

Q9 {% trans "Puis-je ajouter des invités un par un ?" %}

{% trans "Oui, dans la section 'Invités' de votre événement, cliquez sur 'Ajouter un invité'. Saisissez ses informations (prénom, nom, email, téléphone) et sélectionnez une table si nécessaire. Cette méthode est idéale pour ajouter des invités de dernière minute." %}

Q10 {% trans "Y a-t-il une limite d'invités ?" %}

{% trans "Le nombre d'invités dépend de votre plan :" %}
• {% trans "Plan Gratuit" %} : 50 {% trans "invités" %}
• {% trans "Plan Standard" %} : 100 {% trans "invités" %}
• {% trans "Plan Premium" %} : 200 {% trans "invités" %}
• {% trans "Plan Illimité" %} : {% trans "invités illimités" %}
{% trans "Vous pouvez consulter votre plan actuel dans la page de détail de votre événement." %}

Q11 {% trans "Que deviennent les invités qui répondent au RSVP ?" %}

{% trans "Les invités qui confirment leur présence via le lien RSVP sont automatiquement enregistrés dans la liste des réponses. Le système vérifie automatiquement si l'invité fait partie de votre liste pré-enregistrée et l'assigne à la table correspondante. Les invités non vérifiés apparaissent comme 'non vérifiés' pour vous permettre de les valider manuellement." %}

{% trans "Gestion des tables" %}

Q12 {% trans "Comment activer la gestion des tables ?" %}

{% trans "Lors de la création ou de la modification de votre événement, cochez l'option 'Gestion des tables'. Une table par défaut sera créée automatiquement. Vous pourrez ensuite ajouter, modifier ou supprimer des tables selon vos besoins." %}

Q13 {% trans "Comment assigner des invités aux tables ?" %}

{% trans "Deux méthodes sont disponibles :" %}
• {% trans "Assignation manuelle" %} : {% trans "Dans la section 'Tables', sélectionnez un invité et choisissez sa table." %}
• {% trans "Assignation automatique" %} : {% trans "Cliquez sur 'Attribuer' pour que le système place automatiquement les invités dans les tables en fonction de leur capacité." %}

Q14 {% trans "Puis-je exporter le plan de table ?" %}

{% trans "Oui ! Vous pouvez exporter le plan de table au format PDF, CSV ou Excel depuis la section 'Tables' de votre événement. Le PDF est particulièrement utile pour l'imprimer et l'afficher le jour J. Les exports CSV et Excel vous permettent de travailler les données dans un tableur." %}

{% trans "RSVP et communication" %}

Q15 {% trans "Comment mes invités confirment-ils leur présence ?" %}

{% trans "Après avoir créé votre événement, un lien RSVP unique est généré automatiquement. Vous pouvez partager ce lien par email, WhatsApp ou SMS. Vos invités cliquent sur le lien, remplissent le formulaire (présence, nombre de personnes, boisson, etc.) et valident. Leur réponse apparaît instantanément dans votre tableau de bord." %}

Q16 {% trans "Puis-je envoyer des rappels aux invités ?" %}

{% trans "Oui, le système vous permet d'envoyer des rappels automatiques aux invités qui n'ont pas encore répondu. Vous pouvez configurer ces rappels pour qu'ils soient envoyés quelques jours avant l'événement. Les invités reçoivent un email avec le lien RSVP pour confirmer leur présence." %}

Q17 {% trans "Comment personnaliser le message d'invitation ?" %}

{% trans "Lors de la création ou de la modification de votre événement, vous pouvez écrire un message personnalisé dans le champ 'Message d'invitation'. Ce message sera utilisé dans les communications envoyées à vos invités. Vous pouvez aussi personnaliser l'invitation PDF avec la photo de votre événement et votre couleur préférée." %}

{% trans "Paiement et plans" %}

Q18 {% trans "Comment passer à un plan supérieur ?" %}

{% trans "Dans la page de détail de votre événement, cliquez sur 'Choisir un plan'. Sélectionnez le plan souhaité (Standard, Premium ou Illimité), effectuez le paiement via Mobile Money, Orange Money ou Airtel Money, puis soumettez une capture d'écran du reçu. Un administrateur validera votre paiement et votre plan sera activé dans les plus brefs délais." %}

Q19 {% trans "Que se passe-t-il si je dépasse la limite de mon plan ?" %}

{% trans "Lorsque vous atteignez la limite de votre plan, vous ne pouvez plus ajouter de nouveaux invités ni de nouveaux co-organisateurs. Un message vous invite à passer à un plan supérieur. Une fois votre nouveau plan validé, les limites sont automatiquement augmentées et vous pouvez continuer à gérer vos invités." %}

{% trans "Check-in le jour J" %}

Q20 {% trans "Comment fonctionne le check-in avec QR code ?" %}

{% trans "Le jour de l'événement, vous ou vos co-organisateurs (si autorisés) utilisez le scanner intégré dans l'application. Chaque invité reçoit une invitation PDF avec un QR code unique. Scannez ce QR code à l'entrée pour valider sa présence. Le système enregistre automatiquement l'heure d'arrivée. Vous pouvez également saisir manuellement le code court si le QR code n'est pas lisible." %}
